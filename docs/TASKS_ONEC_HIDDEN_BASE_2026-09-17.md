# Скрытая база: панель показывает, а команды отвечают «нет в реестре» (17.09.2026)

**Что наблюдали.** Регистрации базы `nomadstroygroup` в кластере уже нет, а панель её показывает. «Удалить
регистрацию из кластера» заканчивается за доли секунды:

> Базы «nomadstroygroup» нет в реестре. Обновите список из кластера — возможно, она появилась или была удалена

## Разбор

**Агент ни при чём: команда до него не дошла.** Отказ дал сервис до постановки в очередь, по своему реестру
(`ai/src/http/onecRouter.ts:225-228`) — отсюда «меньше 1 с».

**Почему реестр «не знает» базу, которую сам же показывает.** Списки и поиск по ключу расходятся в одном условии:

| Где | Запрос | Скрытые (`disabled_at`) |
|---|---|---|
| список баз для панели — `listAll`, `listByOrganization`, `listByServer` (`ai/src/bases/service.ts:603-630`) | `FROM bases … ORDER BY …` | **показываются** |
| поиск базы для команды — `findByKeyGlobal` (`ai/src/bases/service.ts:640-649`) | `WHERE b.key = $1 AND b.disabled_at IS NULL` | **не находятся** |

Строки реестра сервис не удаляет никогда (`DELETE FROM bases` в коде нет), ключ операции панель берёт из строки
списка. Поэтому «видна в панели, но нет в реестре» бывает только у **скрытой** базы (`disabled_at` задан — «Скрыть
базу» в карточке). Нескрытая база, пропавшая из кластера, нашлась бы, и отказ дал бы уже агент, через секунды.

**Скрытую базу нельзя вернуть и нельзя убрать.** Тот же `findByKeyGlobal` стоит и в маршруте скрытия
(`POST /bases/:key/hidden`, `onecRouter.ts:1426`): «Вернуть в работу» у скрытой базы отвечает тем же «нет в
реестре». Кнопка «Удалить регистрацию из кластера» при этом показывается (`BaseAvailability.tsx:116` — по
`ibUnreachableAt`, без учёта скрытия и статуса) и ведёт на тот же отказ.

**Базу, которой нет в кластере, из реестра не убрать вовсе.** Полный срез ставит ей `MISSING`
(`bases/service.ts:546`), но строка остаётся навсегда, а «Удалить регистрацию» ей бессмысленна: удалять в
кластере уже нечего.

**Проверить на месте:** в карточке `nomadstroygroup` раздел «Доступность» с пометкой «база скрыта» и кнопкой «Вернуть
в работу» — значит, случай этот.
