## Д1. Как читаются договоры

Источник — справочник «Договоры контрагентов». Договоры читаются **одним запросом на базу** для всех организаций.

- В выборку не попадают договоры, помеченные на удаление.
- Папки справочника отсекаются отбором по типу реквизита «Организация»: у папки он пуст.
- Порядок — от новых к старым по `ДатаДоговора`, затем по наименованию.
- Не больше **500** договоров на организацию: лишние отсекает агент, до отправки.

Реквизиты выбираются по метаданным, как у остальных блоков. Если реквизита нет в конфигурации, поле опускается.

| Поле | Откуда | Примечание |
|---|---|---|
| `id` | ссылка договора | GUID |
| `name` | `Наименование` | |
| `number` | `НомерДоговора` | если реквизит есть |
| `date` | `ДатаДоговора` | `ГГГГ-ММ-ДД`; пустая дата не шлётся |
| `validUntil` | `СрокДействия`, иначе `ДатаОкончанияДействияДоговора` | **В БК для Казахстана реквизит называется `ДатаОкончанияДействияДоговора`**: `СрокДействия` там нет |
| `kind` | `ВидДоговора` — представление | «С поставщиком», «С покупателем»… |
| `currency` | `ВалютаВзаиморасчетов.БуквенныйКод` | |
| `counterparty.id`, `.name` | владелец договора: ссылка и представление | |
| `counterparty.bin` | `ИдентификационныйКодЛичности`, иначе `ИдентификационныйНомер` | **В БК для Казахстана БИН/ИИН контрагента — `ИдентификационныйКодЛичности`**. Только цифры; пустой не шлётся |

Правила задачи выполняются так:

- **Пустые поля не шлются.** Договор без наименования и номера пропускается.
- **Сбой чтения** не срывает ответ. Организации уходят без `contracts`, а в корне ответа появляется записка `{block: "contracts", message: "договоры: <текст платформы>"}`. Так же ведут себя остальные блоки. Записка появляется и тогда, когда в конфигурации нет справочника «Договоры контрагентов» или у договоров нет реквизита «Организация».
- **Пустой блок.** Если блок прочитан и у организации договоров нет, поле `contracts` не приходит вовсе, а записки нет. По вашему разбору это «договоров в 1С нет».
- **Персональных данных сверх наименования и БИН/ИИН контрагента в ответе нет.**
