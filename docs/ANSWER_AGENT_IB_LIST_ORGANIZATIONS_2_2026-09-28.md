## Просьба 1 — источник `users` считает только живых пользователей

Настройка «Основная организация» пользователя не учитывается, если это:

- **служебный администратор, под которым входит агент** — сравнение по имени пользователя ИБ;
- **служебный пользователь** — реквизит `Служебный` справочника «Пользователи» (например, «ОтправкаСерверныхОповещений»);
- **пользователь, помеченный недействительным** — реквизит `Недействителен`;
- **пользователь, которому вход запрещён** — у него нет пользователя ИБ (`ИдентификаторПользователяИБ` никого не находит)
  или не разрешены ни вход по паролю 1С, ни вход ОС. Это то же правило «отключён», что у `IB_LIST_USERS`.

Если в конфигурации нет нужных реквизитов справочника «Пользователи», агент считает всех, как раньше.

**Проверено на копии стенда:**

| Настройки | Результат |
|---|---|
| бухгалтер (`support`) → ТОО «ПРЕК»; служебный администратор агента (`bpapi`) и служебный пользователь → ИП Азимов | `main` — ТОО «ПРЕК», `mainSource: "users"` |
| тому же бухгалтеру запрещён вход | `main` нет ни у кого, `mainSource: null` |

## Просьба 2 — `notes` объектами

`notes: [{block, message}]`, где `block` ∈ `contacts | responsible | bankAccounts`, `message` — что сказала платформа.
Туда попадают **только блоки реквизитов**, которые не прочитались.

**Уточнение.** В промежуточной сборке 13:57 туда попадали и сбои определения основной (`block: "main"`). В 15:19 это
исправлено: вы при непустом `notes` склеиваете реквизиты с прошлым чтением (`mergeOrgDetails`). Записка «не прочиталась
константа расширения» держала бы в кэше поля, стёртые в 1С, хотя реквизиты прочитаны полностью. Поэтому сбой определения
основной теперь приходит отдельным полем корня ответа:

```jsonc
{ "items": [...], "mainSource": null, "notes": [],
  "mainNote": "организация по умолчанию расширения: <текст платформы>" }   // только если помешал сбой
```

`mainNote` не обязателен к разбору: `mainSource: null` панель уже показывает как «основная организация базы не определена».
Если захотите — можно дописать к этой строке «(не удалось прочитать: …)».
