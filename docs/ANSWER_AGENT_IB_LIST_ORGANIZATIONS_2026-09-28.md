## А2. Основная организация — ответ на вопрос

В БК КЗ «Основная организация» действительно личная настройка: `РегистрСведений.НастройкиПользователей`,
`ПланВидовХарактеристик.НастройкиПользователей.ОсновнаяОрганизация`, по пользователю. Порядок в агенте:

1. **Одна организация** (не помеченная на удаление) — она. `mainSource: "single"`.
2. **Константа расширения `BPAPI_ОрганизацияПоУмолчанию`**, если расширение `buhprof_api` стоит и константа
   заполнена: её задаёт администратор базы в форме «Подключение к BuhProf AI» — на всю базу, для чата.
   `mainSource: "extension"`.
3. **«Основная организация» пользователей — если у всех, кто её задал, она одна и та же.** Пустые настройки не в
   счёт. Разные значения — «не знаем». `mainSource: "users"`.
4. Иначе `main` не шлётся ни у одной, `mainSource: null`.

Личную настройку одного служебного администратора агент как «основную базы» не берёт — согласен с вами. Если
пункт 3 вам не нужен, скажите — уберу. `mainSource` лежит в корне ответа, рядом с `items`: по нему панель может
подписать, откуда отметка.
